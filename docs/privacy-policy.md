# 개인정보처리방침

**[앱 이름]** (이하 "앱")은 이용자의 개인정보를 소중히 다루며, 다음과 같이 개인정보처리방침을 안내합니다.

시행일: [YYYY년 MM월 DD일]

## 1. 수집하는 개인정보
앱은 이름, 전화번호, 이메일, 위치정보, 기기 식별자 등 **어떠한 개인정보도 수집하지 않습니다.**
회원가입 기능이 없으며, 이용자가 앱에 입력하는 값(예: 매장 추가지원금)은 기기 안에서 계산에만 쓰이고 외부로 전송되지 않습니다.

## 2. 인터넷 사용
앱은 휴대폰 단말기 지원금 정보를 받아오기 위해 인터넷에 접속합니다.
이 과정에서 데이터를 제공하는 서버(GitHub)에 일반적인 접속 기록(IP 주소 등)이 남을 수 있으며, 이는 해당 서비스의 개인정보처리방침을 따릅니다.

## 3. 제3자 제공 및 광고
앱은 개인정보를 제3자에게 제공하지 않습니다.
(광고를 넣는 경우 이 항목을 광고 SDK 내용에 맞게 반드시 수정하세요.)

## 4. 정보의 정확성
앱에 표시되는 지원금·요금 정보는 참고용이며, 실제 구매 조건은 판매처에서 확인해야 합니다.
앱은 이동통신사와 관계없는 개인이 운영합니다.
